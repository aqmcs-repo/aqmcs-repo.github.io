# 🛒 Mercado Online

Sitio web estático para un mercado local, publicado con **GitHub Pages**.  
Muestra los productos disponibles, ofertas y información de contacto del mercado.

## ✨ Características

- 🥦 Catálogo de productos organizados por categorías (frutas, verduras, carnes, lácteos, etc.)
- 📱 Diseño responsive (adaptado a móviles y tablets)
- 🎨 Estilos personalizados con CSS
